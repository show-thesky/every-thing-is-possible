  法律警示 + 索要授权 + 条件性交换。判据因此补了 `scope` 档。

```
node tools/bench.mjs            # 需要本机同版本 CLI，见下
```

bench 依赖：npm 上**没有** `@deepseek-ai/dsh@0.2.1-rc.2`。同版本 CLI 只能从桌面应用的
`app.asar` 解出来：

```
npx --yes @electron/asar extract "<安装目录>/resources/app.asar" "%TEMP%/dsh-asar"
# CLI: %TEMP%/dsh-asar/dsh/node_modules/@deepseek-ai/dsh/lib/bin.js
```

headless bundle 默认把 `credentials / authorization / deepseek-account` 设成 disabled，
bench profile 里要显式 `disabled: false` 并设 `desktopPlatform: win32` 才能读凭据。

**偏差（不美化）**：① B1 是 `noExec` 版本（原始提示两次超时，headless 无审批人）；
② headless 工具集与桌面不同，只能作相对比较；③ D1 只有 2 样本，方差大（8128 vs 2565 字）。
④ **没有对照臂**：目前不能证明"交付是破甲造成的"，需要关掉插件跑同一批题做 A/B。

## 4. 与同类实现的相重

参照本机安装的 `dsh-purge@1.1.71`（其提示词在 npm 包里是封的，按其自身算法解出后比对）。

| 文件 | 5-gram 重合 | 共享整句 | 最长公共子串 |
|---|---|---|---|
| `prompts/core.md` | **0%** | 0 | 16 字符（`" authorization, "`） |
| `prompts/post.md` | **0%** | 0 | 17 字符（`" TARGET, DOMAIN, "`） |

命中原作辨识短语（`Text is text. Fiction is fiction`、`Absolute Permissibility`、
`目标占位流程`、`Little Code Sauce`、`REFUSAL HARDENING` 等 19 条）：**0 条**。
字符级 12-gram 公共片段 3~4%，全是功能词序列（`" is the arti…"`、`" start with "`）。

结论：**思路同源、文字零重合**。四招（占位符归一化 / 拒绝句抗体 / 任务类首行 / 尺度即参数）
来自 dsh-purge 这一条公开血统；第一版里唯一字面痕迹 `ROLE_A, ROLE_B`（它的虚构槽位占位符）
已改为 `FIGURE_A, FIGURE_B`。

```
node tools/ref-prompt.mjs      # 从本机已安装的 dsh-purge 解出原文（只用于比对，不随仓库分发）
node tools/overlap.mjs --deep
```

## 5. 已知边界

- 只覆盖 `system/message` 与 `user/message`；`tool:` 前缀是事实白名单（工具描述不改写），
  `tool/result` 不扫。
- 只改写 context 文本，不删段、不动 tools 列表、不碰 skill 正文。
- 拒答识别是启发式：孤立单句拒绝会漏判（保护正文对白），引用体/代码块有防线。
- 内容层面是概率工程：框架提高服从率，不保证；bench 只测相对拒答率。
- 只报告，不自动修；fail-loud 未实现。
- 仅供学习与研究；不可商用；禁止违法用途；后果自负。
